# Telegram-форма заказа

Форма (`index.html`) собирает данные и отправляет их на backend-функцию
(`api/send.js`), которая хранит токен бота в секрете и отправляет
структурированное сообщение обратно пользователю через Telegram Bot API.

## Шаг 0. Перевыпустите токен бота

Старый токен, который был в исходном коде, уже скомпрометирован (его видел
любой, кто открывал исходный код страницы). Зайдите к **@BotFather** →
`/mybots` → выберите бота → **API Token** → **Revoke current token**,
получите новый и используйте только его дальше.

## Шаг 1. Разверните backend на Vercel

1. Создайте новый репозиторий на GitHub и залейте в него все файлы из этой
   папки (`index.html`, `api/send.js`, `package.json`).
2. Зайдите на [vercel.com](https://vercel.com), нажмите **Add New → Project**
   и импортируйте этот репозиторий.
3. В настройках проекта откройте **Settings → Environment Variables** и
   добавьте:
   - `BOT_TOKEN` = ваш новый токен бота
4. Нажмите **Deploy**. После деплоя Vercel даст вам адрес вида
   `https://ваш-проект.vercel.app`.

## Шаг 2. Подставьте адрес backend в форму

Откройте `index.html`, найдите строку:

```js
const BACKEND_URL = 'https://ваш-проект.vercel.app/api/send';
```

и замените на реальный адрес вашего проекта на Vercel (с `/api/send` в
конце). Закоммитьте изменение — Vercel сам передеплоит проект.

Саму форму (`index.html`) можно оставить на GitHub Pages (как у вас уже
было) — backend и статичная форма могут жить в разных местах.

## Шаг 3. Настройте кнопку в Telegram

У **@BotFather**:

- `/mybots` → выберите бота → **Bot Settings → Menu Button →
  Configure Menu Button**
- Введите URL вашей формы на GitHub Pages
- Введите текст кнопки, например «Оформить заказ»

Теперь у пользователей в чате с ботом снизу будет кнопка, которая открывает
форму прямо в Telegram.

## Как это работает целиком

1. Пользователь нажимает кнопку меню в чате с ботом → открывается ваша
   форма (`index.html`) внутри Telegram.
2. Пользователь заполняет поля и жмёт «Отправить заказ».
3. Форма собирает `tg.initData` (подписанные данные о пользователе и сессии)
   и отправляет вместе с текстом сообщения на ваш backend (`api/send.js`).
4. Backend проверяет подпись `initData` (что запрос действительно пришёл из
   Telegram, а не подделан), затем вызывает
   `https://api.telegram.org/bot<TOKEN>/sendMessage` с вашим секретным
   токеном.
5. Готовое структурированное сообщение приходит пользователю в тот же чат.
6. Форма закрывается (`tg.close()`).

## Локальная проверка backend (необязательно)

```bash
npm install -g vercel
vercel dev
```

Это поднимет `api/send.js` локально на `http://localhost:3000/api/send`.
